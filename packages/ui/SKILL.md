## What's here
- `styles.css` — the **Tailwind v4 + shadcn/ui** theme entry; React apps link this one file. `tokens.css` + `tokens/` — the variables-only token system (colour, type, spacing, radius, shadow, motion, fonts) for non-Tailwind surfaces. Light + dark via `[data-theme="dark"]`. Design against the semantic aliases (`--surface`, `--text-1`, `--border`, `--primary`) / the shadcn utilities (`bg-card`, `text-muted-foreground`).
- `desk.css` + `tokens/desk.css` — the **desk tier**, the admin's tier: an opt-in surface language for the operator's cockpit, linked after `styles.css` and by nothing a marketing site imports. Hanken Grotesk on a dense scale, 32px rows and 30px controls at the desk and 44px under a thumb (the coarse-pointer step is in the tokens), tight 4/6/8px corners, hairline panes, one float shadow, no materials or springs, no new hue. Rules in `BRAND.md` → Desk tier.
- `app.css` + `tokens/app.css` — the **app tier** (retiring — `BRAND.md` → App tier (retiring)): an opt-in second surface language for *operated* screens (the admin PWA), linked after `styles.css` and by nothing a marketing site imports. Translucent materials, real elevation, critically-damped springs, the native type scale on the system font stack, larger corners. Rules in `BRAND.md` → App tier (retiring).
- `assets/logo/` — the 2026 logo: `reference/` (the delivered artwork, 2000px, light + dark, icon + full) and the traced SVGs (`logo-mark*.svg`, `logo-full*.svg`). In React render it through `LogoMark` / `LogoMarkSolid` / `LogoFull` (paths in `src/components/brand/logo-artwork.ts`, traced from the reference and pixel-diffed against it) — never by redrawing it. The full form goes wherever the name has room to read (headers, footers, heroes, 404s, OG cards, logins); the icon everywhere else (favicons, installed icons, bars, the `LogoLoader` loading indicator). `assets/brand/` — social card + email signature. `assets/lib/icons.js` — Lucide `<Icon>` helper for UMD/static surfaces.
- `src/components/desk/` — the desk-tier primitives: `RailItem`, `Pane`/`PaneHeader`/`PaneToolbar`/`PaneBody`, `ListRow`, `StatusDot`, `PriorityTag`, `Kbd`, `DeskSegmentedControl`, `DataGrid` and its parts, `CommandPalette` and its parts, `DeskButton`, `DeskMenu` and its parts, `DeskTabs`, `RecordSection`/`RecordRow`/`RecordBlock`/`RecordDisclosure`. Same barrel, but inert unless the surface links `desk.css`.
- `src/components/app/` — the app-tier primitives (retiring): `GroupedList`/`GroupedSection`/`GroupedRow`/`GroupedBlock`/`GroupedDisclosure` (the inset grouped list), `CollapsingHeader` and its two mastheads `LargeTitleHeader` and `IdentityHeader`, `Monogram`, `ActionCircle`/`ActionCircleRow`, `Material`, and the tier's form controls — `AppField` (label + hint + error + aria wiring) around `AppInput`/`AppTextarea`/`AppSelect`, all 44px by construction rather than by a coarse-pointer media query. Same barrel, but inert unless the surface links `app.css`.
- `src/components/` — idiomatic shadcn/ui primitives (TSX, Button/Card/Input/Badge/Dialog/…) themed with the brand tokens, the glanceable data-viz primitives (Stat / Delta / Sparkline / Meter — inline SVG, no chart library), plus brand-only Eyebrow / IconButton / logo marks / LogoLoader and the motion pieces (Reveal, LogoLockup — motion.dev). Import from the package barrel (`@jamie-nisbet/ui`).

## How to work
- **Voice:** quiet, casual confidence. First person ("I…"), sentence case, no emoji, no hype. Mono for labels/figures. Let numbers carry weight. (Full rules in `BRAND.md` → Content fundamentals.)
- **Visuals:** monochrome — the logo's paper (`#FFFEFA`) and ink (`#1E1E1E`) are the canvas and the tint (ink in light, paper in dark), with warm-grey neutrals between and no second hue; semantic colour only for state, muted. Logo via `--logo-tile` / `--logo-ink`. Hairline borders, generous whitespace, blueprint-grid texture only, soft/low shadows, quick no-bounce motion; one entrance (`Reveal`) and the JN icon as the loader. (Full rules in `BRAND.md` → Visual foundations.)
- **Icons:** Lucide, 1.5–2px stroke. React → `<Icon name="ArrowRight"/>`; static HTML → `<i data-lucide="…">` + `lucide.createIcons()`.

If creating **visual artifacts** (slides, mocks, throwaway prototypes, social cards): copy the assets you need out of this skill and produce static HTML files that link `styles.css`, so the user can view them directly.

If working on **production code**: copy assets and read the rules here to become an expert in designing with this brand. Reuse the component primitives rather than re-implementing them.

If the user invokes this skill without other guidance, ask them what they want to build or design, ask a few focused questions (surface, audience, light/dark, how many variations), then act as an expert designer who outputs HTML artifacts *or* production code, depending on the need.
