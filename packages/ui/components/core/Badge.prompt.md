Compact mono-set label for status, counts and categories. Set in IBM Plex Mono to match the brand's technical accent.

```jsx
<Badge variant="success" dot>Live</Badge>
<Badge variant="primary">v2.4</Badge>
<Badge>Draft</Badge>
```

Variants: `neutral` / `primary` / `success` / `warning` / `danger` / `solid`. Use `dot` for a status indicator.
