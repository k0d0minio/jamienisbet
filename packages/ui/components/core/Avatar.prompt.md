Round avatar with initials fallback.

```jsx
<Avatar name="Jamie Nisbet" />
<Avatar src="/me.jpg" name="Jamie Nisbet" size="lg" />
<Avatar name="JN" size={28} square />
```

Sizes: `sm` 28 / `md` 40 / `lg` 56 / `xl` 80, or pass a number. Without `src` it shows up to two initials on a soft slate tint.
