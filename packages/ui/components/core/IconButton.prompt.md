Icon-only square button for toolbars, cards, and compact controls. Always supply `label`.

```jsx
<IconButton label="Settings"><Settings /></IconButton>
<IconButton variant="solid" label="Add"><Plus /></IconButton>
<IconButton variant="outline" size="sm" label="More"><MoreHorizontal /></IconButton>
```

Variants: `ghost` (default), `solid` (slate fill), `outline`. Sizes `sm`/`md`/`lg`.
