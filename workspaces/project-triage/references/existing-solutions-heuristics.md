# Build vs Buy vs Redirect

> **ICM role:** Layer 3 — reference (project-triage).

Before quoting custom work, ask: is there already a tool that does this?

## Heuristics
- **Buy / Redirect** — an off-the-shelf SaaS solves ≥ ~80% at lower cost/time and the gap isn't worth
  custom money → recommend the tool (and offer to set it up, if that helps).
- **Build** — custom logic, real integration, an AI feature, or a bespoke web presence where no tool fits.
- **Hybrid** — a tool covers the core; Jamie integrates/extends it (often the best value).

## Why redirect at all
A solo consultant's reputation *is* the channel. Sending someone to the right, cheaper answer earns
trust, referrals, and the next (bigger) job. Never sell custom work that a €20/month tool does better.
