# Decision Criteria — GO / REDIRECT / NO-GO

> **ICM role:** Layer 3 — reference (project-triage).

Apply hard gates first, then the weighted score ([`scoring-rubric.md`](scoring-rubric.md)).

## Hard gates (override the score)
- Any deal-breaker (setup) → **NO-GO**.
- A better off-the-shelf solution clearly serves the client
  ([`existing-solutions-heuristics.md`](existing-solutions-heuristics.md)) → **REDIRECT**.

## Score cut-offs (weighted total 0–5)
- **GO** — total ≥ 3.5 **and** budget ≥ floor **and** fit ≥ 3. Qualify → create the client record → proposals.
- **REDIRECT** — fit is low, or a partial DIY/SaaS fit: point them to the better option, honestly.
- **NO-GO** — total < 2.5, or budget below the floor with no strategic upside. Decline politely.
- **2.5–3.5** — borderline: Jamie's call; lead with the limiting dimension.

## Honesty rule
Recommending a competitor or SaaS when it genuinely serves the client better is a **feature** — it
builds trust and referrals. Say so plainly; don't sell custom work that a cheaper tool does better.
