# Intake Checklist (fast capture)

> **ICM role:** Layer 3 — reference (project-triage). The minimum needed to make a triage call —
> works in the 5-minute on-the-spot mode.

Capture only what's needed to decide:
- [ ] **Who** — contact + decision-maker.
- [ ] **The ask** — what they want, in one line.
- [ ] **The real problem / goal** behind it.
- [ ] **Budget signal** — a range, or "no idea".
- [ ] **Timeline.**
- [ ] **Already tried** — any tool they're considering.

Flag unknowns rather than guessing. This feeds the rubric in `02_assessment`. For a full deal, the
exhaustive bank lives in
[`../../proposals/references/discovery-questions.md`](../../proposals/references/discovery-questions.md) —
triage stays deliberately lean.
