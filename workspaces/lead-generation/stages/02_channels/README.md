# Stage 02 — Channels

> **ICM role:** Layer 2 — stage (narrative; contract in CONTEXT.md)
> **Purpose:** Decide and document the low-cost, founder-appropriate channels Jamie will actually run — no paid ads.

## What this folder accomplishes
This stage turns positioning into a concrete channel plan suited to a freelancer who is not a heavy social-media user and is not spending on ads. It formalizes systematized networking (which Mafra/Ericeira/Lisbon events, meetups, and local-business circles to show up at), word-of-mouth and referral asks, lightweight content (occasional case-study posts, a simple portfolio link), and partnerships (e.g. accountants, print shops, web hosts, co-working spaces that refer clients). The output names which channels to run now and which to ignore, with a weekly cadence sized to the capacity in setup.

## Notes
Treat the affiliate program as the highest-leverage channel and reference it rather than duplicating its design. Partnerships should be reciprocal and low-maintenance. Keep the plan short — one page Jamie can act on Monday morning.
