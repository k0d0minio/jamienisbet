# Lead Generation — References

> **ICM role:** Layer 3 — reference
> **Purpose:** Hold the stable positioning notes and channel playbooks the stages read on every run.

## What this folder accomplishes
This folder is the recipe shelf for the lead-gen workspace: stable, reusable knowledge that does not change run to run. It keeps Jamie's positioning notes (segment research, why certain niches fit Mafra/Ericeira/Lisbon, message angles that have worked) and channel playbooks (how to work a local meetup, how to ask for a referral without being pushy, how to brief a partner). Stages pull from here so each run starts from accumulated wisdom rather than a blank page.
