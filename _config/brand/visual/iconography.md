# Iconography

> **ICM role:** Layer 3 — reference (brand visual)
> **Purpose:** Icon style rules so icons across websites and documents look like one set.

- **Style:** line icons, 1.5px stroke, rounded caps/joins. Outline, not filled (matches the clean, approachable feel).
- **Library:** Lucide (open-source, consistent) as the default set; don't mix icon families.
- **Sizing:** 16 / 20 / 24px on a 24px grid; align strokes to the pixel grid for crispness.
- **Color:** `color-muted` by default; `color-primary` for active/emphasis; status colors for status.
- **Don't:** mix outline and filled, use decorative/skeuomorphic icons, or scale below 16px.
