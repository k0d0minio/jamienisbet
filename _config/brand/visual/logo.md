# Logo

> **ICM role:** Layer 3 — reference (brand visual)
> **Purpose:** The logo brief and usage rules. No logo exists yet — this is the spec a designer (or a later pass) produces against; exported files land in [`../assets/`](../assets/).

## Direction (to design)
- A **wordmark** "Jamie Nisbet" set in Inter (600–700), optionally with a compact **"JN" monogram** in a `radius-md` square using `color-primary` with an amber accent detail. Modern, clean, friendly — reads as a person, not a corporation.
- Variants needed: horizontal lockup, stacked lockup, monogram-only; light and dark; SVG + PNG.

## Usage rules (apply once it exists)
- Clear space ≥ the height of the "J" on all sides. Minimum width 120px (horizontal), 32px (monogram).
- On dark backgrounds use the light variant; never recolor outside the brand palette.
- Don't stretch, rotate, add shadows/gradients, or place on a busy background without a solid chip.

## Until then
Use the plain wordmark "Jamie Nisbet" in Inter 700, `color-ink`, as the interim mark.
